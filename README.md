# omp-pulse for Android has moved

This repository is retired. The omp-pulse Android app is now released, together with its source code and the desktop daemon, from [JulianCodespoti/omp-pulse-oss](https://github.com/JulianCodespoti/omp-pulse-oss): download the newest `omp-pulse.apk` from [its releases page](https://github.com/JulianCodespoti/omp-pulse-oss/releases) and install it over your current app (sessions and sign-in are kept). The old [v0.1.0-678 release](https://github.com/JulianCodespoti/omp-pulse-android/releases/tag/v0.1.0-678) stays here unchanged so existing download links keep working, but it will not receive updates.
